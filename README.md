# آوا — آکادمی و استودیو موسیقی 🎵

وب‌سایت رسمی استودیو موسیقی «آوا» — بازنویسی فوق‌حرفه‌ای نسخه‌ی ۲٫۰ با
**صداهای ۱۰۰٪ واقعی** (بدون هیچ صدای مصنوعی/سینثی در بخش شنیداری).

## ✨ امکانات

- **🎧 ۹ قطعه‌ی کامل موسیقی واقعی** — با پلیر سراسری، شکل‌موج واقعی هر قطعه،
  فیلتر ژانر، فهرست پخش، کنترل بلندی و پشتیبانی از Media Session (کنترل از
  نوتیفیکیشن موبایل و مدیاکی‌های کیبورد)
- **🎚 دمو A/B میکس و مسترینگ** — یک قطعه‌ی واقعی از دو مسیر پردازش زنده عبور
  می‌کند: مسیر «خام» در برابر زنجیره‌ی واقعی مسترینگ
  (High-pass → EQ → کمپرسور Glue → لیمیتر → Makeup) با اسلایدر کراس‌فید
- **🎹 پیانوی دو اکتاو با سمپل واقعی** (Salamander Grand Piano) + اجرای کیبوردی
- **🥁 درام‌پد ۸ پداله** با سمپل‌های کیت آکوستیک واقعی + اجرای با کلیدهای ۱ تا ۸
- **🎻 پیش‌نمایش صوتی واقعی هر ۱۶ ساز** آموزشی (هاور/کلیک روی کارت)
- **🚀 بخش هنرمندان**: تنظیم اختصاصی، میکس، مسترینگ و تولید صفرتاصد +
  مسیر شفاف پروژه (۵ مرحله) + ۳ پلن قیمتی + فرم سفارش با لینک دمو
- تم روشن/تاریک، حالت تمرکز (صدای باران)، سوالات پرتکرار، گالری، اساتید،
  مسیر یادگیری، کاملاً ریسپانسیو و راست‌به‌چپ

## 🗂 ساختار پروژه

```
index.html                  ← اسکلت و سکشن‌های صفحه
assets/
  css/style.css             ← کل استایل (تم تیره/روشن، ریسپانسیو)
  js/
    data.js                 ← داده‌ها: ۹ ترک، ۱۶ ساز، ۸ پد، اساتید، گالری
    engine.js               ← موتور صوتی: پلیر، A/B DSP، سمپلر پیانو، وان‌شات
    ui.js                   ← لایه‌ی تعاملی و ویژوالایزرها
  audio/
    tracks/                 ← ۹ قطعه‌ی کامل MP3 (۱۲۸kbps، نرمال‌شده)
    piano/                  ← سمپل‌های Salamander (A3 تا C6)
    drums/  samples/  clips/← سمپل سازها، کیت درامز و برش‌های ارکسترال
    CREDITS.md              ← ذکر منابع و لایسنس‌ها (CC-BY)
```
